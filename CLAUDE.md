# Adevar.ai — Project Context

Economic data dashboard for the Republic of Moldova. Independent monitoring of macroeconomic and energy indicators from official sources (BNS, ANRE, BNM), plus a live news feed from 9 Moldovan RSS sources.

## Quick Commands

- `npm run build` — Build the project (always run before committing)
- `npm run news:pipeline` — Manual news pipeline run (Vercel cron handles this every 5 min)
- `/clean-code` — Safe codebase cleanup (scan first, ask before changing)

## Architecture

- **Framework**: Next.js 15 (App Router, JavaScript — no TypeScript)
- **Database**: Supabase (PostgreSQL)
- **Charts**: Custom canvas rendering engine (`lib/engine.js`)
- **Styling**: Single `app/globals.css`, CSS custom properties for theming
- **Font**: Onest (Google Fonts)
- **Deploy**: Vercel Pro, auto-deploy from `main`
- **News sources**: 9 active RSS feeds (`config/news-sources.json`)
- **Telegram bot**: Public channel @adevar_ai + daily digest to admin

## Vercel Cron Jobs

| Endpoint | Schedule | What it does |
|----------|----------|--------------|
| `/api/cron/news-pipeline` | Every 5 min | Fetches RSS feeds, deduplicates, scores, tags, upserts to Supabase |
| `/api/cron/sync-statbank` | Daily 03:00 UTC | Syncs indicator data from BNS StatBank |
| `/api/cron/daily-digest` | Daily 07:00 UTC (9am Chisinau) | Sends personal Telegram summary to admin |
| `/api/cron/telegram-notify` | Not scheduled | Called by sync-statbank when data changes |

All cron routes are protected by `CRON_SECRET` (Bearer token auth).

## Monitoring

- **Health check**: `/api/health/news` — returns `healthy` or `stale` (stale if last successful run >15 min ago)
- **Daily Telegram digest** at 9:00 AM Chisinau to admin (`TELEGRAM_ADMIN_CHAT_ID`)
- `news_runs` and `news_errors` tables for pipeline history
- DB cleanup via pg_cron: `news_errors` (60 days), `news_runs` (90 days)

## News Pipeline

- 9 active RSS sources from Moldovan news outlets (2 disabled: unimedia-md blocks bots, moldova1-md has no RSS)
- Custom regex XML parser (no external RSS library)
- Deduplication: hard dedup by `url_hash` (UNIQUE), soft dedup by `duplicate_group` (first 8 title words)
- Impact scoring: source priority (high=50, medium=30) + keyword bonuses (+8 each)
- Tag classification: `economie`, `energie`, `social` based on keyword matching
- Feed API deduplicates by `duplicate_group` before returning to frontend

## Data Pipeline

- StatBank PxWeb API syncs daily at **03:00 UTC** via Vercel cron
- Rate limit StatBank requests to **1 req/s** — the API will block faster rates
- Supabase has a **frequency check constraint** on indicator rows: valid values are `yearly`, `monthly`, `quarterly`

## Rules

- **Three languages**: All user-facing text must support RO, EN, and RU via `t()` from `useLang()`
- **Build before committing**: Always run `npm run build` and verify it passes before committing
- **Branch first**: Always create a new branch before making changes
- **Never modify existing chart JSONs** in `data/charts/` — they are generated by sync scripts
- **Commit style**: `type(scope): description` — types: `fix`, `feat`, `chore`, `ci`, `docs`, `refactor`, `security`
- **No TypeScript**: This is a JavaScript project. Do not add `.ts`/`.tsx` files
- **Prefer editing over creating**: Edit existing files rather than creating new ones when possible
- **Never touch**: `.env` files, lock files, `node_modules`, `.next`
- **Never force push to main**
- **Test before merge**: Run build, verify no errors

## Gotchas

- Chart pages use `export const dynamic = 'force-static'` (SSG) — they are statically generated at build time
- `ShareButtons` component uses `position: absolute` — its parent must have `position: relative` or buttons will be invisible (clipped by `overflow: hidden` on `.main-content`)
- `ChartCanvas` is dynamically imported with `ssr: false` — canvas code cannot run server-side
- The `ComingSoon` component renders when `chart.soon` is truthy or `chartData` is null
- API routes use server-side Supabase client from `lib/supabase-server.js` — never import the browser client in API routes
- News feed filters map UI keys to Romanian tag names: `economy` -> `economie`, `energy` -> `energie`, `social` -> `social`
