# adevar.ai — Design System

## Grid
- Base unit: 8px
- Common spacings: 4, 8, 12, 16, 24, 32

## Colors
- Light: bg `#f5f6f8`, surface `#fff`, border `#d2d6de`, accent `#1e3f6e`
- Dark: bg `#121620`, surface `#181d2c`, border `#2e3548`, accent `#7baade`

## Typography
- Font: Inter (Google Fonts)
- Scale: 10px label, 11px meta, 12px small, 13px body, 14px default, 15px title, 18px brand, 20px heading, 28px stat value

## Principles
- No glow, no neon, no gradients on interactive elements
- WCAG AA contrast on all text
- Subtle shadows only (`shadow-sm`, `shadow-md`)
- Transitions: 150ms (fast), 200ms (normal)
