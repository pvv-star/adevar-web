**Codebase health verdict:** The project improved significantly since Feb 28. The three most critical findings from the previous audit are all fixed. The new news pipeline is well-designed but introduces new security surface area (SSRF, Telegram injection, rate limiting gaps). The custom Canvas chart engine is an excellent bundle-size decision. The main concerns are runtime correctness (the P0 crash), serverless rate limiting architecture, and production build optimization.

## 2. Security & Stability

### Fixed From Previous Audit ✅
- **Supabase anon key fallback (was P0):** `mustEnv()` now throws if `SUPABASE_SERVICE_ROLE_KEY` is absent.
- **innerHTML XSS in engine.js (was P1):** Comprehensive `esc()` function wraps every dynamic value. `safeHref()` guards URLs.
- **CRON_SECRET validation (was P1):** All cron routes validate `Bearer ${CRON_SECRET}` with double guard.

### New Findings

| ID | Sev | Finding | File | Action |
|----|-----|---------|------|--------|
| S1 | P1 | **Ingest auth checked after DB query.** Unauthenticated callers can enumerate indicator slugs via 404 vs 403 response. | `app/api/ingest/indicator-value/route.js` | Move `validateIngestAuth()` before any Supabase query. |
| S2 | P1 | **In-memory rate limiters don't work in serverless.** `Map`-based state not shared across Vercel function instances. Limits only enforced within a single warm container. | `lib/ingest-rate-limit.js`, `lib/server-rate-limit.js` | Replace with Upstash Redis or Vercel Edge rate limiting. |
| S3 | P2 | **CSP has `unsafe-eval` + `unsafe-inline`** — effectively nullifies XSS protection. | `vercel.json` | Remove `unsafe-eval`. Replace `unsafe-inline` with nonces. |
| S4 | P2 | **API routes have zero security headers.** The `vercel.json` header block excludes all `/api/*` paths. | `vercel.json` | Add second header block for `/api/(.*)`. |
| S5 | P2 | **SSRF in news pipeline.** `rssUrl` from config fetched without scheme/hostname validation. `file://` or cloud metadata URLs would be followed. | `app/api/cron/news-pipeline/route.js` | Add URL allowlist: HTTPS only, no private IPs. |
| S6 | P2 | **Telegram HTML injection.** RSS titles interpolated into `parse_mode: 'HTML'` without escaping. Malicious feed could inject phishing links into admin digest. | `lib/telegram.js` | HTML-escape all dynamic values with `escTg()`. |
| S7 | P2 | **`CRON_SECRET` absent from `.env.example`.** New deployments will have broken crons with no documentation. | `.env.example` | Add `CRON_SECRET` with generation instructions. |
| S8 | P2 | **Open ingest endpoint by default.** `INGEST_API_TOKEN` commented out in `.env.example`. Copying the file unmodified = no auth on ingest. | `.env.example`, `lib/ingest-auth.js` | Default to strict mode. |
| S9 | P2 | **`/api/news/by-tag` missing rate limiting** — the only unprotected public route. | `app/api/news/by-tag/route.js` | Add `applyRateLimit()` call. |
| S10 | P3 | News pipeline processes sources sequentially (9 sources × 10s timeout = 90s worst case, exceeds 60s `maxDuration`). | `app/api/cron/news-pipeline/route.js` | Parallelize with `Promise.allSettled()`. |
| S11 | P3 | BNM XML parser returns `null` silently when all rates fail — API returns `ok: true` with null values. | `app/api/widgets/live-snapshot/route.js` | Return degraded response indicator. |
| S12 | P3 | `fetch-cache.js` GC interval only runs in browser, not server-side. Stale entries persist. | `lib/fetch-cache.js` | Run GC unconditionally. |

## 4. Production Impact

| ID | Sev | Finding | Action |
|----|-----|---------|--------|
| P1 | P1 | **5 Onest font weights** (400/500/600/700/800 × latin+cyrillic) loaded on every page. ~200-300KB of fonts. Previous audit flagged this — still not fixed. | Reduce to `['400', '600', '700']`. ~100KB savings. |
| P2 | P1 | **Redundant Google Fonts preconnect links** in layout.js. `next/font/google` handles this automatically. | Remove the two `<link rel="preconnect">` tags. |
| P3 | P1 | **News pipeline cron at `*/5 * * * *`** — 288 runs/day. Sequential RSS fetching means 90s worst case, exceeds 60s `maxDuration`. No mutex prevents overlapping runs. | Change to `*/15`. Add Supabase-based mutex lock. Parallelize source fetching. |
| P4 | P1 | **`.claude/settings.json` committed to repo** — AI hooks config with shell command execution. Security risk in shared repo. | Add `.claude/` to `.gitignore`. |
| P5 | P2 | **`images: { unoptimized: true }`** disables ALL Next.js image optimization globally. Currently low-impact (only SVGs) but a landmine for future media content. | Remove global flag. Use per-image `unoptimized` for SVGs only. |
| P6 | P2 | **No bundle analyzer** configured. No visibility into what actually ships to client. | Add `@next/bundle-analyzer` and `npm run analyze` script. |
| P7 | P2 | **`100vh` on app-layout** cuts off content on iOS Safari where 100vh includes browser chrome. | Use `100dvh` (dynamic viewport height). |
| P8 | P2 | **Cache-Control `public, max-age=3600`** on all non-API routes — may cache news pages with stale content. | Differentiate: static assets get `immutable`, dynamic pages get `s-maxage=60, stale-while-revalidate=300`. |
| P9 | P2 | **Smoke tests only run on `workflow_dispatch`**, not after deploys. Breaking changes go undetected. | Trigger critical smoke tests after pushes to `main`. |
| P10 | P3 | **`poweredByHeader: false`** not set — `X-Powered-By: Next.js` header exposed on API routes. | Add to `next.config.js`. |
| P11 | P3 | **`reactStrictMode: true`** not set. | Add for dev safety. |

### Architectural Strengths ✅
- **Config-driven chart architecture** — adding a new chart is just adding a JSON entry + running sync. Scales to hundreds of indicators without code changes.
- **Custom Canvas chart engine** — zero third-party chart deps, ~590 lines handles animated line charts with full interactivity. Excellent bundle-size decision.
- **Clean server/client boundary** — RSC pages handle metadata/SEO, client components handle interactivity.
- **No circular dependencies** — clean `app/ → components/ → lib/` dependency graph.
- **Good deployment hygiene** — `boss-preflight.sh`, `validate-env.sh`, ignore rules for checkpoint branches.
